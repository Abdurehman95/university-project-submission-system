# 🎓 University Project Submission System (UPSS)

[![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)](https://reactjs.org/)
[![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)](https://vitejs.dev/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

A modern, efficient, and user-friendly platform designed to streamline the project submission and evaluation process for universities. This system bridges the gap between students, instructors, and administrators, providing specialized dashboards and tools for each role.

---

## 🌟 Key Features

### 👨‍🎓 For Students
- **Project Submission:** Easily upload and manage project files and documentation.
- **Progress Tracking:** Real-time visibility into submission status and grading.
- **Course Material:** Access guidelines and rubrics provided by instructors.
- **Personal Dashboard:** A centralized overview of upcoming deadlines and recent feedback.

### 👨‍🏫 For Instructors
- **Assignment Management:** Create, edit, and publish new project requirements.
- **Efficient Grading:** Dedicated interface for reviewing submissions and providing detailed feedback.
- **Student Performance:** Analytics and overviews of class-wide project progress.
- **Resource Sharing:** Upload templates and reference materials for students.

### 👨‍💼 For Administrators
- **User Management:** Full control over student and instructor accounts.
- **System Configuration:** Manage university departments, courses, and academic terms.
- **Reports & Analytics:** Generate system-wide reports on project completion rates and performance.
- **Audit Logs:** Monitor system activity for security and compliance.

---

## 🚀 Technology Stack

- **Frontend:** [React 19](https://react.dev/) with Hooks and Functional Components.
- **Build Tool:** [Vite 7](https://vitejs.dev/) for ultra-fast development and optimized builds.
- **Routing:** [React Router 7](https://reactrouter.com/) for seamless navigation.
- **Animations:** [Framer Motion](https://www.framer.com/motion/) for smooth, premium transitions.
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/) for a consistent visual language.
- **Styling:** Custom [Vanilla CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) with modern features like Variables, Flexbox/Grid, and Glassmorphism.

## 🛠️ Getting Started

Follow these steps to set up the project locally:

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Abdurehman95/university-project-submission-system.git
   cd university-project-submission-system
   ```

2. **Navigate to the frontend directory:**
   ```bash
   cd react-app
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Launch the development server:**
   ```bash
   npm run dev
   ```

5. **Open your browser:**
   Navigate to `http://localhost:5173` to view the application.
